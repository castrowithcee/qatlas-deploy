# qdeploy

qdeploy (Qatlas Deploy) runs as a service on a Linux host and keeps the Docker stacks of that host rolled out
and up to date from its stacks repository.

## Building

Go 1.26 or newer is required.

```sh
go build -o qdeploy .
```
